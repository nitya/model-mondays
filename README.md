Model Mondays is a practical livestream series for building model expertise one week at a time. Explore model capabilities, selection, customization, and the patterns that help developers build effective AI agents with Microsoft Foundry.

- **Model Mondays:** livestreams featuring model news, technical spotlights, and demos.
- **Foundry Fridays:** [on-demand expert AMAs](docs/foundry-fridays/README.md), numbered independently from seasons.
- **Models for Beginners:** [self-guided curriculum](https://aka.ms/models-for-beginners).
