# Model Mondays assets

Episode banners use `S<season>-E<episode>.png`, for example `S4-E7.png`.

- Preferred size: 1920×1080 (16:9).
- Preferred format: optimized PNG.
- The season/episode text embedded in the artwork must match the filename and episode page.
- Pages reference banners as `../assets/model-mondays/S4-E7.png`.

Do not add placeholder dates or copy current banners into `data/assets/`.
